# DFS

```
DFS(G, u)
    state[u] = “discovered”
    process vertex u if desired
    time = time + 1
    entry[u] = time
    for each vertex v that is adjacent to u
        process edge (u, v) if desired
        if state[v] = “undiscovered” then
        p[v] = u
        DFS(G, v)
    state[u] = “processed”
    exit[u] = time
    time = time + 1
```
